02 Bonsai 2 · local

Bonsai 2. A 27B model on your laptop.

Ternary Bonsai 2 27B fits a 27B-class model into 5.9 GB, and PrismML says it keeps 98.2% of the full-size model's benchmark score.

PrismML built it from Qwen3.8 27B and stored the language model's weights as one of three values: -1, 0 or +1. That's how a model that takes about 54 GB at full precision fits in 5.9 GB. It reads text and images, has a 262K-token context window, and is released under the Apache 2.0 licence. It runs on a Mac, on Windows or Linux with a GPU, or on a CPU alone, and your prompts stay on your machine.

Set it up on a Mac or Linux

PrismML's demo repo does the whole install. Open a terminal and run:

git clone https://github.com/PrismML-Eng/Bonsai-demo.git
cd Bonsai-demo
./setup.sh

That fetches the model and the right llama.cpp build for your machine. Then start the chat server and open http://localhost:8080 in your browser:

./scripts/start_llama_server.sh

That one local page gives you chat, image input and tool calling.

Set it up on Windows

Same repo, PowerShell instead:

git clone https://github.com/PrismML-Eng/Bonsai-demo.git
cd Bonsai-demo
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\setup.ps1

Then start the server and open http://localhost:8080:

.\scripts\start_llama_server.ps1

Get the most out of it

  • 1Turn the thinking down for everyday questions.It's a reasoning model and thinks at xhigh effort by default, which is most of the wait on slower machines. In the chat page, click the lightbulb in the message box and pick a lower Reasoning effort. To make medium the default for the whole server, start it like this. PrismML says medium thinks noticeably less and is about as accurate. 
    ./scripts/start_llama_server.sh --chat-template-kwargs '{"reasoning_effort":"medium"}'
  • 2Give it room to answer.It thinks before it answers, so a small output cap ends it mid-thought. PrismML suggests -n 16384 or more, or a high max_tokens if you call it from your own code. If you do, skip reasoning_effort: "low": it isn't supported and behaves close to xhigh.
  • 3Skip the extras if you only want chat.The setup script also installs Open WebUI and a code interpreter, which add a few GB and most of the wait. Set BONSAI_OPENWEBUI=0 and BONSAI_CODE_INTERPRETER=0 to skip them.
  • 4Use the 4-bit cache for long documents.BONSAI_KV4=1 cuts KV-cache memory roughly 3.5x, which matters once you push the context toward its 262K limit.
  • 5Use PrismML's build, not stock llama.cpp.Stock llama.cpp can't run these files yet, and one format loads anyway and produces gibberish. The setup script installs the right build for you.
The download is 7.8 GB, because the demo defaults to a packing of the weights that reads prompts faster, plus the file that handles images. Speed depends on your hardware. PrismML measured up to 46.8 tokens a second on an M5 Max laptop and up to 143 on an NVIDIA RTX 5090.

03 Qwen-Image · local

Qwen-Image-2.1. Images and edits on your own GPU.

Qwen-Image-2.1 makes and edits images in one model, including images with transparent backgrounds, and the weights are free to download.

In the Reel I called it Qwen Image 2.5. The release is Qwen-Image-2.1, so search for that name. The image generation part has 7B parameters and makes 2K images natively. It takes up to 10 reference images, so you can turn six portraits into one group photo or build an outfit from five product shots. You can also circle part of a picture and say what to change there.

Read the licence before you use it for work. Qwen-Image-2.1 is under the Qwen Research License, which allows research and evaluation only. Commercial use needs a separate licence from Qwen, and the licence file says how to ask.

Try it before you install

Qwen runs a free demo on Hugging Face. Try a few prompts there first so you know it's worth the download: Qwen-Image-2.1 demo.

Option 1: ComfyUI, no code

  • 1Get ComfyUI.Qwen says ComfyUI has supported Qwen-Image-2.1 natively since launch day.
  • 2Download the model files.Get them from Comfy-Org/Qwen-Image-2.1 on Hugging Face and put each one where that page says, inside your ComfyUI folder: models/diffusion_models, models/text_encoders and models/vae.
  • 3Load a workflow.Open the text to image or image edit workflow. These are the examples Qwen's README links.

Option 2: Python, with Diffusers

This is Qwen's own quick start. It runs on an NVIDIA GPU, because the example sends the model to CUDA. Install the libraries first:

pip install "torch>=2.4.0"
pip install "transformers>=5.17"
pip install git+https://github.com/huggingface/diffusers
pip install accelerate
pip install pillow

I added the quotes around the first two lines. Without them your shell reads > as "write to a file" and leaves a stray file behind.

Then save this as qwen_t2i.py and run python qwen_t2i.py. The first run pulls the weights from Hugging Face.

import torch
from diffusers import QwenImage21Pipeline

pipe = QwenImage21Pipeline.from_pretrained(
    "Qwen/Qwen-Image-2.1", torch_dtype=torch.bfloat16
).to("cuda")

image = pipe(
    prompt="A neon shop sign that reads \"QWEN IMAGE 2.1\", rainy night, reflections on wet pavement",
    num_inference_steps=40,
    generator=torch.Generator("cuda").manual_seed(42),
).images[0]

image.save("t2i_example.png")

Short on GPU memory? Qwen gives one switch for that: load the pipeline without .to("cuda") and turn on CPU offload. Qwen doesn't publish a minimum VRAM figure.

pipe = QwenImage21Pipeline.from_pretrained(
    "Qwen/Qwen-Image-2.1", torch_dtype=torch.bfloat16
)
pipe.enable_model_cpu_offload()

Get the most out of it

  • 1Let Qwen write the long prompt.For best results Qwen recommends its prompt rewriting models, which expand a short prompt into a detailed one. There's one for text to image and one for editing.
  • 2Use the transparency prompt.For a transparent background, this is the format Qwen recommends: 
    This is an RGBA image with transparency. <your description>. The image has alpha channel and the background is transparent.
  • 3Use its native sizes.2048 × 2048 for square, 1536 × 2752 for 9:16 and 2752 × 1536 for 16:9. The README lists the rest.
  • 4Start at 40 steps.It's Qwen's default and every example in the README uses it.
  • 5Edit by circling.Draw circles or paint over an area and describe the change. If you don't want marks on the picture, pass the original image and a separate mask instead.

04 DeepSeek · open weights

DeepSeek V4.1 Flash. Open weights, priced for agents.

DeepSeek V4.1 Flash is open weights under MIT, but at 552B parameters most people will get more out of it through DeepSeek's API.

It's a mixture-of-experts model that uses just 8B active parameters for input and 16B for output, with a 1M-token context and image input. DeepSeek says tests by multiple parties put it ahead of the bigger V4-Pro on performance, cost and speed, and it's phasing V4-Pro out. Its KV cache needs a quarter of the memory of the last generation's. That matters for agents, because cache-hit charges are often a large share of what an agent costs to run.

Per 1M tokensOff-peakPeak
Input, cache hit$0.003$0.006
Input, cache miss$0.15$0.30
Output$0.60$1.20
Peak hours are 01:00 to 04:00 and 06:00 to 10:00 UTC, Monday to Friday. Every other hour is off-peak, including weekends and Chinese public holidays. Prices are from DeepSeek's pricing page, which says they can change. In the API the model is called deepseek-flash.

Use it inside Claude Code

DeepSeek's docs include a setup that points Claude Code at DeepSeek's API, so you keep Claude Code's agent and DeepSeek does the thinking. Get an API key from the DeepSeek Platform, then run this in your terminal on a Mac or Linux:

export ANTHROPIC_BASE_URL=https://api.deepseek.com/anthropic
export ANTHROPIC_AUTH_TOKEN=<your DeepSeek API Key>
export ANTHROPIC_MODEL=deepseek-flash[1m]
export ANTHROPIC_DEFAULT_OPUS_MODEL=deepseek-flash[1m]
export ANTHROPIC_DEFAULT_SONNET_MODEL=deepseek-flash[1m]
export ANTHROPIC_DEFAULT_HAIKU_MODEL=deepseek-flash
export CLAUDE_CODE_SUBAGENT_MODEL=deepseek-flash
export CLAUDE_CODE_EFFORT_LEVEL=max
export CLAUDE_CODE_AUTO_COMPACT_WINDOW=786432

Then go into your project and start Claude Code:

cd /path/to/my-project
claude

The Windows version of those commands is on the same DeepSeek page. Web search works too: DeepSeek runs it through its own API and bills the extra tokens. The docs have guides for Codex, OpenCode and other agents as well.

Run the weights yourself

You can if you have a multi-GPU server. DeepSeek's own code is in the inference folder of the model repo, and DeepSeek calls it "a readable reference implementation rather than a production serving engine". Its example splits the model across 8 GPUs (MP=8). From that folder, install, convert the Hugging Face weights, then chat:

python -m pip install -r requirements.txt
export HF_CKPT_PATH=/path/to/DeepSeek-V4.1-Flash-HF
export SAVE_PATH=/path/to/DeepSeek-V4.1-Flash-TP8
export MP=8

python convert.py \
  --hf-ckpt-path "${HF_CKPT_PATH}" \
  --save-path "${SAVE_PATH}" \
  --model-parallel "${MP}" \
  --expert-dtype fp4 \
  --tokenizer-path "${HF_CKPT_PATH}"
export CKPT_PATH=/path/to/DeepSeek-V4.1-Flash-TP8
export MP=8

torchrun --nproc-per-node "${MP}" generate.py \
  --ckpt-path "${CKPT_PATH}" \
  --config config.json \
  --interactive \
  --temperature 0.6

For your own client, the model card recommends temperature 1.0, top_p 0.95 or 1.0, and room for at least 256K output tokens. The chat example above uses 0.6.

DeepSeek doesn't list a minimum spec on the model card. My suggestion: unless you already run a GPU server, use the API. Hugging Face also lists community quantizations for llama.cpp, Ollama and LM Studio. DeepSeek didn't make those, so check who did before you download one.

05 Grok 4.7

Grok 4.7. Built for the long jobs.

SpaceXAI trained Grok 4.7 on problems that take many hours to complete, and says it works longer on hard tasks and checks its own work more carefully.

It's SpaceXAI's most capable model for coding and knowledge work. It costs $2 per million input tokens and $6 per million output, with a 500K-token context window, and SpaceXAI says it's twice as fast at half the price of comparable models.

Where to use it

  • Grok Build, SpaceXAI's coding agent. It runs on Grok 4.7 by default and you can try it free. Install it from your terminal: 
    curl -fsSL https://x.ai/cli/install.sh | bash
  • Cursor, on all plans.
  • The xAI API, as grok-4.7, or through OpenRouter, Vercel and Cloudflare.

Get the most out of it

  • 1Pick the reasoning level.Over the API you can set low, medium, high or xhigh. High is the default.
  • 2Set a prompt cache key.SpaceXAI "highly recommends" a prompt_cache_key on the Responses API. It sends a conversation's requests to the same server, which makes cache hits reliable. Without it you often pay full input price.
  • 3Use Fast when speed beats cost.Grok 4.7 Fast is the same model on faster servers at twice the token price. It's only in Cursor and Grok Build.
  • 4Turn on search for anything current.Its knowledge stops at May 2026. In the API, enable the Web Search or X Search tools when you need live information.

06 GPT-6 Sol + Luna

GPT-6 Sol and Luna. GPT-6 for less.

OpenAI trained Sol and Luna with methods similar to GPT-6 Astra's, then priced them 50% below GPT-5.6's promotional rates.

Per 1M tokensInputOutput
GPT-6 Sol$2$10
GPT-6 Luna$0.10$0.50

Which one to pick

Pick Sol for hard work. OpenAI pitches it at difficult work tasks, with higher usage limits and lower cost. Pick Luna when you run a lot of requests: on OpenAI's factuality test, Luna at higher effort matches GPT-5.6 Sol at about a hundredth of the cost. For the hardest work, OpenAI still calls GPT-6 Astra its best model across the board.

Where to use them

In ChatGPT Work and Codex on Plus, Pro, Business, Enterprise and Edu. Free and Go users get Luna in the desktop app. OpenAI says they aren't in Chat yet. In the API they're gpt-6-sol and gpt-6-luna.

Get the most out of them

  • 1Build around the cache.OpenAI improved prompt caching for GPT-6 and gives a 90% discount on cached input reads.
  • 2Change effort without losing the cache.You can raise reasoning effort for a hard step, lower it for a quick follow-up, and switch tools on or off, and the earlier context stays cached.
OpenAI has since shipped GPT-6.1 Sol, an upgrade to Sol at the same price. It's in section 08.

07 Claude 5.5

Claude 5.5. Opus for judgment, Sonnet for speed.

Anthropic builds Opus 5.5 for complex work that needs careful judgment, and Sonnet 5.5 for well-scoped everyday tasks.

Per 1M tokensInputOutputCache reads
Opus 5.5$4$20$0.20
Sonnet 5.5$2$10$0.20

Both are on every platform, including AWS, Google Cloud and Microsoft Azure. In the API they're claude-opus-5-5 and claude-sonnet-5-5.

Opus 5.5

Anthropic says it performs at the level of Claude Fable 5.1 on most work and costs 40% less to run than Opus 5. It's particularly good at long, sprawling jobs like codebase-wide migrations and audits. Anthropic also raised the five-hour usage limits on Pro, Max, Team and seat-based Enterprise plans.

Sonnet 5.5

It's strongest at fixing bugs and making polished documents, slides and spreadsheets, and it runs 30%+ faster than Sonnet 5. On Anthropic's own table it beats Opus 5.5 on one benchmark, Terminal-Bench 4.0, at 70.6% to 66.4%. Anthropic says Opus 5.5 is still clearly stronger at complex, open-ended work.

Get the most out of them

  • 1Set the effort yourself.On the API, Opus 5.5 runs at medium effort unless you set it (Opus 5 ran at high). Sonnet 5.5 defaults to medium in the Claude apps and high on the Claude Platform. My suggestion: turn effort up for the long, hard jobs and leave it at medium for quick ones.
  • 2Plan with Opus, build with Sonnet.One early tester quoted on Anthropic's Sonnet page said that once Opus 5.5 sets the architecture, they'd trust Sonnet 5.5 to implement it.
  • 3Use fast mode when you're waiting on it.Opus 5.5 has a fast mode in Claude Code and on the Claude Platform, up to 2.5x faster, at $8 per million input tokens and $40 per million output.
  • 4Leave thinking on.Opus 5.5 always thinks, and the API rejects a request that turns thinking off. Use the effort setting to control how deep it goes.

09 What to do now

Pick one. Use it today.

Reading about eight models changes nothing. Pick the one that fits your work and put a real task through it today.

  • If you want a private model on your laptop: start at 02, Bonsai 2. One setup script, then you're chatting.
  • If you make images and have an NVIDIA GPU: start at 03, Qwen-Image-2.1. Try the free demo first.
  • If you code with agents and watch the bill: start at 04 and run DeepSeek V4.1 Flash inside Claude Code.
  • If you run long coding jobs in Cursor: start at 05 and try Grok 4.7.
  • If you live in ChatGPT or Codex: start at 06, then go straight to GPT-6.1 Sol in 08.
  • If your work is complex and needs careful judgment: start at 07 with Opus 5.5.
