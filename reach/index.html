01 · The repo

Agent Reach. One install, most of the internet.

Agent Reach gives your agent a working route into platforms that normally block it: Reddit, Instagram, LinkedIn, YouTube, X and more. No paid APIs.

It doesn't do the reading itself. For each platform it picks the most reliable free tool, installs it, checks it works, and keeps a fallback ready for when that tool breaks. Your agent then calls those tools directly. Run agent-reach doctor and it tells you which route each platform is using right now.

02 · Install

Paste one line. Your agent does the rest.

You don't install this by hand. You give your agent the install guide and it works through it.

1 · Paste this into Claude Code or Codex

Install Agent Reach: https://raw.githubusercontent.com/Panniantong/agent-reach/main/docs/install.md

The link points at the repo's install guide, which is written for agents. Yours installs the Python package, checks your machine and tells you what's ready. By default it only checks. Anything that touches your system needs a --system flag, and the guide tells the agent to ask you first. Say yes when you're happy with what it lists.

The README names Claude Code, OpenClaw, Cursor and Windsurf, and says it works with any agent that can run commands. It doesn't mention Codex by name, but Codex runs shell commands, so the same line works there.

2 · Check what's working

agent-reach doctor

This lists every platform as ready, needs setup, or broken, with the fix. Web pages, YouTube, GitHub and RSS work straight after install, and web search is set up during it. Reddit, Instagram, LinkedIn and X need the setup in section 03.

Prefer to do it yourself?

The repo's install guide recommends pipx:

pipx install https://github.com/Panniantong/agent-reach/archive/main.zip
agent-reach install --env=auto

That second command only checks. Once you've read its list, this one installs the missing pieces:

agent-reach install --env=auto --system

On a Mac with Homebrew Python you might see an externally-managed-environment error. That's Python's own protection, not a bug in the tool. Use pipx as above, or install inside a virtual environment.

Add it as a skill

The README also ships it as a skill for Claude Code and any agent with skills support. Once the skill is in, your agent checks for the agent-reach command and installs it if it's missing.

npx skills add Panniantong/Agent-Reach@agent-reach

Keep it current

Tools break when platforms change. When something stops working, paste this into your agent:

Update Agent Reach: https://raw.githubusercontent.com/Panniantong/agent-reach/main/docs/update.md
03 · Set up each platform

Unlock what you need. Skip the rest.

Every channel past the basics is optional. Set up the ones you'll use and ignore the others.

You can ask for them all in one go. Your agent reads the install guide, installs what each platform needs and tells you which steps only you can do.

Set up the Reddit, Instagram and LinkedIn channels in Agent Reach. Follow the install guide, tell me each step I have to do myself, then run agent-reach doctor and show me the result.

YouTube · nothing to set up

YouTube works straight after install. Paste a link and ask what the video covers. Under the hood your agent pulls the subtitles with yt-dlp:

yt-dlp --write-sub --write-auto-sub --skip-download -o "/tmp/%(id)s" "URL"

It can search YouTube too, and it can pull comments, though the repo's own docs call comment extraction best-effort. If a video has no subtitles, agent-reach transcribe "URL" downloads the audio and transcribes it with Whisper. That needs a free Groq API key.

Reddit and Instagram · one Chrome extension

Both run through OpenCLI, which reuses the session in your own Chrome. So you log in the normal way and your agent reads what you can see. Instagram only works on a desktop, not on a server.

  • 1Install OpenCLI.Your agent runs this after you approve it:
    agent-reach install --system --channels opencli
  • 2Add the Chrome extension.This is the one step your agent can't do for you, because Chrome won't allow it. Add OpenCLI from the Chrome Web Store.
  • 3Check the connection.Run opencli doctor. You want to see "Extension: connected".
  • 4Log in.Open reddit.com and instagram.com in that Chrome and log in. For Instagram, the install guide also has your agent run:
    agent-reach install --system --channels facebook,instagram

What your agent runs once that's done:

opencli reddit search "query" -f yaml
opencli reddit read POST_ID -f yaml
opencli instagram search "query" -f yaml
opencli instagram user nasa -f yaml
Reddit has no zero-setup route. The README says its anonymous endpoints are blocked, so it needs a logged-in session either way. On a server with no browser, the install guide falls back to a tool called rdt-cli and your agent will switch to it. Instagram search finds users, not posts by keyword. To read posts, give your agent a username. If Instagram starts returning 429 or login errors, log in again in Chrome and slow down.

LinkedIn · public pages now, full profiles after one login

Public LinkedIn pages work straight away through Jina Reader. For full profiles, company pages, people search and job search, tell your agent:

help me set up LinkedIn

It installs a LinkedIn MCP server (linkedin-mcp-server) and then asks you to log in once:

uvx mcp-server-linkedin@latest --login

A browser opens and you log in to LinkedIn yourself. The session is saved in ~/.linkedin-mcp/profile/. The docs list profiles, companies, people search and job search. They don't list reading post comments, so don't count on that.

Twitter/X · a cookie export

Tell your agent "help me configure Twitter cookies". It walks you through exporting your login from the Cookie-Editor extension: log in to x.com, click the extension, then Export, then Header String, and paste it to your agent.

04 · Get the most out of it

Five prompts. Research, leads, insight.

Installing it is the easy part. The value comes from asking for things your agent couldn't reach before.

Swap the brackets for your own topic, market or product. Each prompt names the platforms it needs, so set those up first.

1 · Deeper research · Reddit, YouTube, web search

Using agent-reach, research [topic]. Search Reddit for the most discussed threads on it and read the full threads with their comments. Find the most relevant YouTube videos on it and pull their subtitles. Search the web with Exa for recent articles. Then tell me what people agree on, where they disagree, and which claims only appear in one source. Link the source for every point.

2 · Finding leads · LinkedIn

Using agent-reach with the LinkedIn channel, search for people with the title [role] in [location]. For the ten best matches, pull their profile experience and their company's profile. Give me a table with name, role, company, and one line on why they might need [what I sell]. Read only. Don't message or connect with anyone.

3 · Finding leads · Reddit

Using agent-reach, search Reddit for posts where people ask for help with [problem I solve]. Read each thread with its comments. List the ten posts where the person sounds ready to pay for a fix: the subreddit, the link, and their problem in their own words. Read only. Don't reply to anything.

4 · Customer insight · Reddit, YouTube

Using agent-reach, read the top Reddit threads about [product or competitor] and the comments on the most-watched YouTube reviews of it. Group what people complain about and what they wish it did into themes. For each theme, give me three exact quotes with links, and tell me how often it came up.

5 · Competitor scan · Instagram

Using agent-reach with the Instagram channel, pull the recent posts from @[account 1], @[account 2] and @[account 3]. For each account, list the topics they keep coming back to and the formats they repeat. If the output includes like or comment counts, rank the posts by them. Go slowly between accounts.
The repo's skill file tells your agent to say which platform and route it's using before it starts. If it doesn't mention agent-reach, it's probably using its normal web tools. Ask it to use agent-reach.
05 · Use it responsibly

Your account. Your call.

For the platforms that block agents, this works through your own login. So the risk sits with your account.

Here's how it gets in, from the repo's own docs. Reddit, Instagram and Facebook go through your logged-in Chrome session via OpenCLI. X uses cookies you export yourself. LinkedIn saves a login session on your machine. The README says cookies stay local and are never uploaded.

The install guide itself recommends a separate account, not your main one, for any platform that needs cookies or a browser session. It gives two reasons:

  • Your account can be restricted or banned. Platforms may spot requests that don't come from a normal browser.
  • Cookies give full access to the account. If they leak, a secondary account limits the damage.

Automated reading while logged in can break a platform's terms of service, and each platform's terms are yours to check. Keep it read-only, go slowly, and back off when a platform starts returning errors. The skill file itself says it's for fetching content, not for posting, commenting or liking.

One more from the README: Agent Reach has no token, coin or crypto project. If something using its name asks you to connect a wallet or claim fees, it isn't them.
