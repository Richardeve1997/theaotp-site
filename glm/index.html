01 · The model

Which GLM, and why it matters.

The cheap one is GLM-5.3-Flash. Not GLM-5.3. The names are one word apart and the price is thirty times apart, so get this right before you paste anything.

GLM-5.3-Flash is the model Zhipu ran in stealth on OpenRouter as "Ox Alpha" from 20 August, then revealed on 26 August. It went to #1 on the OpenRouter weekly leaderboard, which OpenRouter called its biggest launch to date. It is 320B total parameters with 18B active, 1M context, natively multimodal, MIT licensed.

Plain GLM-5.3 is the older, bigger sibling at $1.4 in / $4.4 out per million tokens. Everything on this page uses Flash.

03 · The swap

Two lines. Then run claude.

Claude Code reads its endpoint and token from two environment variables. Point them at Z.ai's Anthropic-compatible endpoint and the harness swaps the model under the hood. Nothing else changes.

If you don't have Claude Code yet:

npm install -g @anthropic-ai/claude-code

Then, in the terminal you run Claude Code from, paste your key into the second line and run:

export ANTHROPIC_BASE_URL=https://api.z.ai/api/anthropic
export ANTHROPIC_AUTH_TOKEN=YOUR_ZAI_KEY
claude

That's the whole swap. Claude Code starts as normal, reads your CLAUDE.md, loads your skills and MCP servers, and every request goes to GLM-5.3-Flash instead of Anthropic.

Make it stick. Those exports only last for the terminal session. To have a dedicated command that always runs Claude Code on GLM, add this to your ~/.zshrc (or ~/.bashrc), then open a new terminal and type glm:

glm() {
  ANTHROPIC_BASE_URL=https://api.z.ai/api/anthropic \
  ANTHROPIC_AUTH_TOKEN=YOUR_ZAI_KEY \
  claude "$@"
}

Because the variables are set only for that one command, plain claude still runs on your Anthropic account. You get both, side by side, and you choose per task.

Pinning the model slots. If Claude Code ever asks for a model name it doesn't recognise, Z.ai's docs give the three overrides that map its Opus, Sonnet and Haiku slots to Flash. Add them to the same block:

export ANTHROPIC_DEFAULT_OPUS_MODEL=glm-5.3-flash
export ANTHROPIC_DEFAULT_SONNET_MODEL=glm-5.3-flash
export ANTHROPIC_DEFAULT_HAIKU_MODEL=glm-5.3-flash

Reference: docs.z.ai, Claude Code with GLM. Never paste your key into a file you commit or share.

04 · Your setup

Nothing about your stack changes.

This is the part people miss. You are not switching tools. You are swapping the engine inside the tool you already run.

Your CLAUDE.md still loads. Every SKILL.md is untouched. Your MCP servers connect with the same config. Your workflows, hooks and slash commands run exactly as before, because Claude Code is the harness and the harness did not change. The same is true if you drive the Codex CLI or another harness: the model behind it is a setting, not an identity.

What you should expect to change: cost, and the character of the model. GLM-5.3-Flash is a different model with different habits. Give it the same CLAUDE.md and skills and you'll get close, but read its first few plans before you let it run.
