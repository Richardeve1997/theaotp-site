01Start here

One skill that finds the others.

find-skills is a free skill from Vercel. You tell Claude what you're working on, and it goes and finds the right skill for the job, then installs it.

Andrew Qu, Vercel's Chief of Software and the person who built skills.sh, wrote it in January 2026. On 9 November it was the number one skill on the skills.sh leaderboard with 4.3 million installs, out of 1,286,018 skills listed there. That's the whole problem it solves: there are far too many skills to browse, and most people either spend ages looking or never install one at all.

02The install line

Install it once.

Run this in your project's terminal. It needs Node.js 22.20 or later.

npx skills add vercel-labs/skills --skill find-skills

Add -g at the end to make it available in every project, not just this one. It works in Claude Code, Codex, Cursor, OpenCode and more than 75 other coding agents.

npx skills add vercel-labs/skills --skill find-skills -g

Then just ask for what you want, the way you'd ask a person: "make me a pitch deck", "help me review this contract", "set up tests for this app". When a skill exists for it, Claude reaches for find-skills on its own.

Skills run inside a coding agent such as Claude Code, because they install with a terminal command.

03How it picks

It checks the numbers before it installs.

find-skills doesn't grab the first match. Its own instructions tell it to check quality first.

1

Leaderboard, search, check, install.

It looks at the skills.sh leaderboard first, because the most installed skills are usually the tested ones. If nothing fits, it searches with npx skills find. Before it recommends anything it checks three things: over 1,000 installs, a known source like Vercel, Anthropic or Microsoft, and a GitHub repo with real stars. Then it shows you the options and installs the one you choose.

When I asked skills.sh for "pitch deck", the top results were pitch-deck from Anthropic's financial-services skills (2,527 installs), pitch-deck from ailabs-393 (1,733) and yc-pitch-deck (838). By its rules, the official Anthropic one is the pick.

04The goal-first prompt

Describe the goal, not the steps.

This is the prompt I use to stay goal-orientated. Fill in the two brackets and paste it into Claude.

Here's my end goal: [what done looks like, who it's for, and how I'll judge it].

Before you start:
1. Ask me the questions you need answered, one at a time, until you know what good looks like.
2. Work out the plan yourself. Don't wait for me to give you steps.
3. Check which skills and tools you already have. If a skill would do part of this better, use find-skills to search for one, tell me what you found and how many installs it has, and wait for my yes before you install it.
4. Show me the plan in a few lines, then do the work.

Here's one example of what good looks like: [paste an example you like].

Step 3 is where find-skills comes in. Claude only installs a skill after you say yes.

05Why it works

The model is better at the plan than you are.

Spell out every step and Claude follows them, even when they're the wrong steps. Give it the end goal and it plans the work and picks the tools.

2

Steps cap the result. A goal doesn't.

Vercel runs about 100 skills behind one internal data science agent, and they've found the model picks the right one from a plain question. Andrew Qu told Anthropic:

"We've found that Opus, specifically Opus 4.8, is very good at matching intent to skills."Andrew Qu, Chief of Software, Vercel

Their one rule for it: give every skill a descriptive name and description, so the model can match your goal to it.

06Before it installs

Check what you're installing.

Anyone can publish a skill, and a skill works with whatever access your Claude has.

  • 1Read the source.Prefer skills from the company that makes the tool, and look at the repo before you say yes.
  • 2Look at the audits.Every skills.sh page shows its security checks. find-skills itself shows two passes and one warning.
  • 3Clear out the overlap.Too many skills that do the same job make it harder for Claude to pick the right one. npx skills list shows what you have and npx skills remove takes one out.

  • 1You've never installed a skill.Run the install line in section 02, then ask Claude for the next thing on your list.
