02 · Install, both agents

Claude Code, then Codex.

I run both, so here is how to set it up properly in each one. Pick whichever you use, or do both like I did.

Claude Code, from your terminal:

/plugin marketplace add sergebulaev/linkedin-skills /plugin install linkedin-skills@linkedin-skills

Or clone it straight into your working directory, no plugin install needed:

git clone https://github.com/sergebulaev/linkedin-skills.git cd linkedin-skills

Codex CLI:

codex plugin marketplace add sergebulaev/linkedin-skills codex plugin add linkedin-skills@linkedin-skills

Or the one command that works across Claude Code, Codex, Cursor and any agent that reads SKILL.md files:

npx skills add sergebulaev/linkedin-skills
Skills and Plugins need a paid Claude plan (Pro, Max, Team or Enterprise) with code execution enabled. Once installed, just ask for help with LinkedIn and the right skill activates on its own.

04 · Optional: auto-post

Publora. Two minutes, then Claude can publish directly.

By default every skill drafts for you to copy and paste. Connect Publora and Claude Code or Codex can publish straight to LinkedIn, and optionally X, Threads and Instagram too.

  1. Sign up free at app.publora.com/signup
  2. Click Channels, then Add Channel, pick LinkedIn, authorize
  3. Click your LinkedIn account under Channels and copy the Platform ID (looks like linkedin-ABC123DEF)
  4. Click Settings → API → Create Key, copy the sk_... string
  5. Drop both into a .env file in the linkedin-skills folder
Free tier gives 15 posts a month. It is the layer under the skills; this bundle adds the reading, the writing craft and the approval flow on top.
05 · What to do now

Two hours this week. That's the whole ask.

Install it, then ask for one thing today. Reading the skill list does nothing until you use it on your own post.

  • If you have never posted on LinkedIn: run the Interviewer first. It builds your Story Bank so every later draft has real material instead of guessing.
  • If you post occasionally but inconsistently: ask the Content Planner for a 7-day plan today, then the Post Writer for day one.
  • If your main platform is Instagram, X or YouTube: start with the Repurposer. It is the fastest way to see output without writing anything new.
  • If you already post but it never goes anywhere: run Post Audit on your last draft before you publish it, then Hook Extractor on the best post in your niche this week.
