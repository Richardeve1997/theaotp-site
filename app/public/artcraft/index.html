02Download

Download them free on Mac, Windows or Linux.

The easiest route is the ArtCraft Launcher. Install it once and it installs every app, picks the right build for your computer and keeps them all up to date.

  • 1Get the launcher.

    Click Download Launcher on getartcraft.com/apps, or pick a file from the launcher's latest release on GitHub. There's a disk image for Mac (Apple silicon and Intel), installers for Windows on 64-bit, 32-bit and ARM PCs, and Linux packages.

  • 2Or install one app on its own.

    Each app's page on getartcraft.com has its own installers, and so does the Releases section of its GitHub repo. Most apps also have a web build that runs in a browser.

  • 3Expect updates often.

    Eleven of the 13 apps put out a new version on 18 October. The launcher is the low-effort way to stay current.

They cost nothing. The code is open source under the MIT or Apache 2.0 licence, and GridCraft's README promises no subscription and no licence server. GridCraft's Mac builds are signed and notarized, and its Windows installers are code-signed.

03Connect to Claude

Let Claude build your spreadsheet.

Every ArtCraft app can be driven by an AI agent. GridCraft's MCP server lets Claude build a spreadsheet without you opening the app.

MCP, the Model Context Protocol, is the standard way AI tools such as Claude plug into other apps. GridCraft's README puts it plainly: every ribbon button, menu item, dialog, keystroke and mouse gesture is a command an agent can run.

  • 1Get the command-line tool.

    On a Mac, download gridcraft-cli-<version>-macos-universal.zip from GridCraft's latest release, unzip it and move gridcraft-cli into a folder on your PATH, the list of folders your terminal looks in for commands. The release only ships this tool for Mac. On Windows or Linux, the docs build it with Rust's cargo, from inside a copy of the GridCraft repo:

    cargo install --path apps/gridcraft-cli
  • 2Add it to Claude Code.

    Run this in your terminal. It runs GridCraft headless, which means no window, just the engine.

    claude mcp add gridcraft -- gridcraft-cli mcp

    Want to watch it work? Start the desktop app with its control channel on (gridcraft --control 7979), then add this one instead:

    claude mcp add gridcraft-app -- gridcraft-cli mcp --connect 7979
  • 3Using Claude Desktop or another app?

    The docs give this config for Claude Desktop and say it works for other clients too:

    {
  "mcpServers": {
    "gridcraft": {
      "command": "gridcraft-cli",
      "args": ["mcp"]
    }
  }
}
  • 4Ask for the model.

    Then ask in plain English. This prompt is mine, not from the docs. Swap in your own numbers.

    Use GridCraft to build a five-year financial model for my business in a new workbook: revenue, costs, profit and margin for each year, all as formulas. Start revenue at [your number] and grow it [your rate] a year. Format the margin row as a percentage, add a column chart, and save it as model.xlsx.

    Behind the scenes Claude calls GridCraft's tools, such as write_range to fill cells, format_range, insert_chart and save_workbook. It saves a normal .xlsx, so you can open the result in Excel too.

Commands from GridCraft's MCP docs and README, checked on 19 October 2026. The other apps follow the same pattern: WordCraft's is claude mcp add wordcraft -- wordcraft-cli mcp, and each app's README has a section for agents. The docs name Claude Code and Claude Desktop. Codex, Cursor and other agents that take MCP servers can use the same command in their own settings.
04REA

Reverse Engineer Anything: what it does and doesn't.

REA gives your AI agent the tools to look inside an app, work out how a feature works, and then write its own version for your project. It doesn't hand you the original's source code.

What it does

REA plugs into your agent through MCP. Point it at an app and it returns evidence. For a native app that's pseudocode and assembly from an analysis tool such as Hopper, Ghidra or IDA. For a JavaScript or Electron app it's the app's modules and how they connect. Your agent reads that evidence, explains how the feature works, then writes and tests its own version. The analysis runs on your computer.

What it doesn't do

It doesn't recover the original source code, and it doesn't copy an app for you. The agent writes new code from what it learned. The project's disclaimer says it won't help with copying proprietary software, getting around licence checks or DRM, or game cheats. It's meant for software you own or are allowed to examine, and reverse engineering can be restricted by law or by an app's licence, so check before you point it at anything.

Set it up

You need Node.js 22.19 or later on version 22, 24.11 or later on version 24, or version 26 and up. Run this, choose your agents, approve the changes and restart your agent. Setup supports Claude Code, Codex, Cursor, Gemini CLI and others.

npx rea-agents setup

Then ask. This is the README's own example; swap in the app and feature you care about.

Understand how search works in the Notes app, show me the evidence, and build a similar feature for my project.

JavaScript and Electron apps need nothing extra. Deeper analysis of native apps needs Hopper, Ghidra or IDA, and setup can install Hopper if you approve it. More walkthroughs are in the REA guides.

05Personalised software

Personalised software for your business.

The future of personalised software has never been clearer. Instead of paying for a bloated app where you don't use half the features, you ask a team of AI agents to work overnight and build you a version with the 5% you actually use.

That's a big advantage if you're building an AI-native business right now. Your whole tech stack can be personalised.

For scale: Excel has 523 worksheet functions, and GridCraft already covers 513 of them, according to its README. How many does your business use every week?

Where I'd start

  • Pick one paid app your team only half uses. Try the ArtCraft version for a week on copies of real files.
  • Find one feature you love in a tool you rely on. Ask your agent, with REA, how it works, then have it build that feature into something you own.
  • Keep the paid tool for live work until the replacement has proved itself on your files.

07What to do now

Pick your starting point.

Reading about free software won't save you money. Start with the line that fits you.

  • If you pay for Adobe or Office and only use the basics: install the launcher and open a copy of a real file in the matching app (section 02).
  • If you use Claude Code: connect GridCraft and ask it for a model of your business (section 03).
  • If there's a feature you love in another tool: set up REA and ask your agent how that feature works (section 04).
