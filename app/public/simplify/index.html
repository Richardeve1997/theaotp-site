02 · How it works

Seven rungs. Stop at the first one that holds.

Before it writes a line, the agent checks each rung in order and stops the moment one of them answers the problem.

  1. Does this need to exist? No: skip it. YAGNI.
  2. Already in this codebase? Reuse it, don't rewrite it.
  3. Stdlib does it? Use the standard library.
  4. Native platform feature? Use it.
  5. Installed dependency? Use it.
  6. One line? One line.
  7. Only then: the minimum that actually works.
It reads the code the change touches and traces the real flow first. It is lazy about the solution, never about understanding the problem. Trust-boundary validation, data-loss handling, security and accessibility are never on the chopping block, that's the part a bare "write fewer lines" prompt drops.

04 · Install, both agents

Claude Code, then Codex.

Needs `node` on your PATH, that is the whole prerequisite. Pick whichever agent you use.

Claude Code, two separate prompts (the install needs both):

/plugin marketplace add DietrichGebert/ponytail /plugin install ponytail@ponytail

Codex:

codex plugin marketplace add DietrichGebert/ponytail codex plugin add ponytail@ponytail
On Codex, run codex then open /hooks, review and trust its two lifecycle hooks, and start a new thread. If node is not on your PATH the skill still installs, it just stays quiet instead of activating automatically on every prompt.
05 · What to do now

Give it a real feature. Not a toy prompt.

The gap only shows up on a task with a real over-build trap: a picker, a form, a settings panel. A trivial task shows almost nothing.

  • If you have not installed it yet: run the two Claude Code commands above, then ask for something you would normally reach for a library on, a date picker, a color picker, a dropdown.
  • If you already feel your agent over-builds: pick your last PR that felt bloated, revert it, and redo it with ponytail on. Diff the two.
  • If you manage a team using AI agents: the benchmark method is public. Run it on your own repo before deciding whether the numbers transfer to your codebase.
