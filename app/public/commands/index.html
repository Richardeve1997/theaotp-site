01 · Start here

The five worth learning first.

If you only try five things on this page, try these. Three show you how you use Claude Code and keep it sharp, one does a day of research for you, and one stops you pasting the same background into every chat.

  1. 01
    Claude Code

    Builds an HTML report on your recent sessions: which projects you work in, how you use Claude Code, where things go wrong, and features worth trying. Run it once a month and read it like a performance review of your own habits.

  2. 02
    Claude Code

    Shows how full the context window is as a coloured grid, with suggestions for what is taking up space. Check it before a long task. Anthropic's own docs say performance degrades as context fills.

  3. 03
    Claude Code

    Summarises the conversation so far to free up context, and you can tell it what to keep, for example /compact keep the pricing decisions. Use it when a long research or writing session starts to drift.

  4. 04
    ChatGPT

    Type it in the ChatGPT prompt box to start a deep research task. ChatGPT plans the research, works through sources and writes it up as a documented report. Use it for anything you would otherwise spend an afternoon searching for.

  5. 05
    Claude app

    Gives one piece of work its own knowledge base and instructions. Upload the documents once and every chat in that project uses them. Make one per client, report or recurring job. Free accounts get up to five.

02 · Claude Code commands

Claude Code, beyond code.

Claude Code runs on any folder, not just a codebase. Point it at a folder of notes, drafts or client documents and these commands work the same way.

Type / in a session to see every command you have. These are the ones I would learn next.

  1. 06

    Starts a fresh conversation with empty context. Use it between unrelated tasks, because leftover context from the last job makes the next one worse. The old session stays on disk, so /resume can bring it back.

  2. 07

    Opens a picker of past conversations, or resumes one by name or ID. Pick up yesterday's research thread exactly where you left it.

  3. 08

    Rolls the conversation, the files, or both back to an earlier point. Use it when a draft goes sideways and you would rather restart from the last good version.

  4. 09

    Exports the conversation as plain text, to a file or your clipboard. Handy for turning a working session into notes, a handover or a record of decisions.

  5. 10

    Opens your CLAUDE.md files, the standing instructions Claude reads at the start of every session, plus the auto memory switch. Put your writing style, audience and house rules here once.

  6. 11

    Creates a CLAUDE.md guide for the folder you are in. Run it once in a new project so every later session starts with the basics already loaded.

  7. 12

    Asks a side question without adding it to the conversation. Good for "what was that file called again?" halfway through a task.

  8. 13

    Puts Claude in plan mode, so it works out a plan before it changes anything. Add a description to start straight away, for example /plan outline the Q3 board report.

  9. 14

    Switches the model and saves it as your default. Use a bigger model for hard thinking and a faster one for quick edits.

  10. 15

    Sets how hard the model thinks: low up to xhigh or max, or auto. Turn it up for analysis and down for quick jobs.

  11. 16

    Writes a one-line summary of the session on demand. Useful when you come back to a long session and need your bearings.

  12. 17

    Copies the last response to your clipboard, and /copy 2 grabs the one before it. If the answer has code blocks, it lets you pick one.

  13. 18

    Shows session cost, plan usage limits and activity stats. /cost and /stats open the same screen.

  14. 19

    Gives the session access to another folder. Pull in a folder of research notes or client documents without moving anything.

  15. 20

    Sets up routines that run in the cloud on a schedule, and Claude walks you through it in plain English. Good for anything you currently do by hand every week.

03 · Claude Code keys

Keys and prompt words.

These are typed, not run. Each one saves a few seconds, and you will use them dozens of times a day.

  1. 21

    Cycles permission modes: Manual, accept edits, plan, and auto when it is available. Tap it into plan mode before any big task.

  2. 22

    With text in the box, double Esc clears the draft and Up brings it back. With an empty box, it opens the rewind menu.

  3. 23

    Start a line with ! to run a shell command directly. The output lands in the session and Claude responds to it.

  4. 24

    Type @ to mention a file with autocomplete, so Claude reads exactly the document you mean.

  5. 25

    Put this word anywhere in a prompt to ask for deeper reasoning on that one turn without changing your effort setting. The docs are clear that "think hard" and "think more" are plain text, not keywords. This is the only one that counts.

  6. 26

    Ask Claude to remember something, like "remember that I write in UK English", and it saves it to auto memory for future sessions. Say "add this to CLAUDE.md" to make it a standing instruction instead.

  7. 27

    Opens your prompt in your text editor, so you can write a long brief properly instead of on one line.

  8. 28

    Stashes the prompt you are typing and clears the box. Press it again on an empty box to bring it back. Useful when a quick question interrupts a long brief.

04 · ChatGPT

ChatGPT commands and shortcuts.

ChatGPT only has a few real slash commands, so this list mixes those with the settings and shortcuts that change how it works for you.

Nothing here is a made-up slash command. If it starts with /, OpenAI's help centre documents it.

  1. 29

    Type / in the message box and pick Search to make ChatGPT search the web and cite its sources. Open the citations: OpenAI's own help centre says results can be incomplete, outdated or wrong.

  2. 30

    Type it in the composer to start agent mode, where ChatGPT carries out a task step by step and stops to ask when it needs clarification or confirmation.

  3. 31

    This is where custom instructions live: tell ChatGPT who you are and how you want answers. They apply to every chat straight away, existing ones included. On iOS and Android it is Settings > Customize ChatGPT.

  4. 32

    Ask ChatGPT to remember a preference or detail and it saves it for future chats. Ask it to forget one, or delete it in Memory settings.

  5. 33

    Select New project in the sidebar to keep related chats, files and instructions together. Add your reference files once and stop pasting the same background into every chat.

  6. 34

    Open a new chat and select Temporary. It stays out of your chat history and is not used to improve OpenAI's models while it stays temporary. OpenAI may keep a copy for up to 30 days for safety.

  7. 35

    On the ChatGPT Mac app, the default shortcut opens the Chat Bar from anywhere, so you can ask a question, upload a file or grab a screenshot without switching windows.

05 · Claude app

The Claude app, set up properly.

Most people use the Claude app as a blank chat box. These features give it context, memory and a way to do real research.

  1. 36

    Account-wide instructions that apply to every conversation: your role, the terms you use and how you like answers laid out.

  2. 37

    On paid plans, ask Claude to search your past conversations and it pulls that context back in. Try "What did we discuss about the pricing page?"

  3. 38

    Tell Claude to remember this and it saves the detail to memory straight away. Turn memory on or pause it in Settings > Memory.

  4. 39

    On paid plans, click + then Research and Claude runs several searches that build on each other, across the web and connected tools like Gmail, Calendar and Google Docs, then answers with citations. Web search has to be switched on.

  5. 40

    Click the ghost icon on a new chat for an incognito chat. It is not saved to your history or to memory and is not used for training. It is not available inside projects.

  6. 41

    On Claude Desktop for Mac, turn on quick entry and this opens Claude from any app, so you can ask a question or share a screenshot or window without switching.

  7. 42

    In quick entry, once you switch on the voice shortcut, press Caps Lock to dictate your message and press it again to stop. It is off by default because it takes over the key.

06 · Codex CLI

Codex, from the terminal.

Codex is OpenAI's agent for your terminal. Type / in a session for the full menu. These are the ones that keep long jobs on track.

  1. 43

    Creates an AGENTS.md file, the standing instructions Codex reads for that folder. Write your rules once instead of repeating them every session.

  2. 44

    Switches to plan mode so Codex proposes a plan before it starts work. Add a prompt and it sends it straight away.

  3. 45

    Sets a goal Codex keeps tracking while a long task runs. You can edit, pause, resume or clear it.

  4. 46

    Opens an ephemeral side chat for a quick question without disturbing the main transcript.

  5. 47

    Summarises the visible chat to free tokens after a long run, so Codex keeps the key points without hitting the context limit.

  6. 48

    Resumes a saved chat from your session list, so you keep working without starting over.

  7. 49

    Shows the active model, the approval policy and how much context you have left, plus token usage.

  8. 50

    Picks a communication style: more concise, more explanatory or more collaborative, without touching your instructions.

07 · What to do now

Pick one. Use it today.

Reading a list of fifty commands changes nothing. Using two of them this week will.

  • If you use Claude Code: run /insights today, then check /context before your next long task (01, 02).
  • If you mostly use ChatGPT: set your custom instructions, then try /Deepresearch on a question you would normally spend an afternoon on (31, 04).
  • If you mostly use the Claude app: make one project for your main piece of work and turn on Research for the next big question (05, 39).
  • If you use Codex: run /init in your project, then give your next long task a /goal (43, 45).
