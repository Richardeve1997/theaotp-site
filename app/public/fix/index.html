01 · The setup prompt

Paste once. Check that it stays on.

Paste this into Claude Code, where the agent can install the skill and configure new sessions.

Installing a skill and activating it are different steps. This prompt asks for both, then asks for proof of what changed.

Set up the I Have ADHD response skill from https://github.com/ayghri/i-have-adhd so it applies by default in my new Claude Code sessions.

First read the repository's current INSTALL.md and the canonical skills/i-have-adhd/SKILL.md. Use the documented Claude Code setup, not instructions guessed from memory.

If you can access my local Claude Code installation:
1. Check whether the plugin is already installed. Install it at user scope if needed, using the current upstream instructions. Preserve my existing configuration and other plugins.
2. Enable the repository's documented always-on option for my actual Claude configuration directory. At the time this prompt was written, that is the .i-have-adhd-always flag used by the plugin's SessionStart hook. Verify the current guide before making that change.
3. Confirm the plugin is enabled and the always-on flag is in the correct directory. Do not claim a new session was tested unless you actually tested it.
4. Apply the style in this conversation now. Tell me one short test to run in a new Claude Code session, and how to return to on-demand use.

If you are a browser chat or cannot access those settings, say so plainly. Read the rules if you can; otherwise ask me to paste them. Then give me a short version I can save in my Claude personal instructions, followed by the exact manual setup steps appropriate to the tool I am using. Do not claim to have saved settings you cannot change.

Keep answers practical: lead with the action, use short numbered steps, state where we are in the task and end with one next action. Explain fully when I ask. Do not invent time estimates or omit details that change the answer.
A Claude Code plugin does not automatically change Claude on the web or your phone. If that is where you chat, use the prompt's saved-instructions route and save the resulting rules yourself. It should tell you what it could and could not configure.
02 · Verify it

Open a new chat. Try one real task.

A successful install message is not the same as the response rules being active.

  1. Open a fresh Claude Code session after setup.
  2. Ask it to turn a messy task into a short plan. The useful action should appear first, with a clear place to pick up again.
  3. If it still rambles, ask it to check the installed plugin and the always-on flag against the installation guide.

The current guide uses a SessionStart hook and an opt-in flag for Claude Code. Without the flag, the skill stays on-demand. You can activate it explicitly with /i-have-adhd.

To stop using it by default, ask Claude Code to remove only that flag using the guide's return-to-on-demand instructions. You can also say “stop adhd mode” for the current session.

04 · Use it today

Try it on the task you keep reopening.

Give Claude the current state and ask for the next action.

For example: “I'm halfway through my cover letter. Here is the draft and the job description. Tell me what to change first, and keep track of what we have finished.”

This changes the assistant's response style. It does not install a medical treatment or guarantee a particular productivity improvement.
