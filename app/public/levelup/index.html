01 · The prompt

One prompt. Your whole history.

Paste this into Claude, ChatGPT or Codex. It reads back through your past chats, finds the work you keep repeating, and asks you before it builds anything.

Repeated work becomes a skill. A skill is a saved set of instructions your AI follows every time, so you stop explaining the same deck or report from scratch. Work tied to a day or a time becomes a scheduled task, which runs on its own. Checking your tools and planning the week every Monday? That becomes a task that runs at 8am on Monday.

Look through my whole conversation history with you and find the work I keep doing by hand. I want the repeated work turned into skills and my weekly routines turned into scheduled tasks.

1. Read my history
Go through every past conversation you can reach. Use your chat search or memory tools, and if you can read files, check my saved session logs too. Tell me how far back you got.

2. Find the repeated work (skills)
Look for anything I've asked for three or more times in the same way: the same kind of deck, document, report, email or analysis, made with roughly the same steps.
For each one, write down:
- what I make and how often
- the steps I follow, in order
- what a good result looks like, using my best past example
- the inputs I give you each time

3. Find the routines (scheduled tasks)
Look for work tied to a day or a time: things I do every Monday, at the end of each week, before a regular meeting or at the start of each month.
For each one, write down:
- what I do and when
- which tools and sources I check
- what I end up with
- the day and time it should run

4. Show me the list
Give me one table of the top 10, ranked by the hours each would save me a month. For each item, say whether it should be a skill or a scheduled task, how many times you found it, and one conversation where it came up. Then stop and ask me which ones to build.

5. Build the ones I approve
For each skill I pick, write a SKILL.md with a name, one line on when to use it, the steps in order, the output format and my best example. If you can create skills yourself, do it. If you can't, give me the full file to paste in.
For each scheduled task I pick, write the exact prompt it should run, when it runs and where the result goes. If you can schedule tasks yourself, set it up and confirm it. If you can't, tell me how to set it up in the tool I'm using.

Rules
- Only use what's really in my history. Never invent a pattern.
- If something is unclear, ask me before you build it.
- Keep each skill and each task to one job.
It only uses what's in your history. If it finds nothing that repeats, it says so. It won't invent a pattern to fill the table.
02 · How to run it

Four steps. Then you pick.

The prompt can only find what it can see. So the first step is making sure it can see your history.

  • 1Let it see your history.In Claude, searching past chats is on paid plans (Pro, Max, Team, Enterprise). Go to Settings > Memory and check "Search and reference chats" is on. In ChatGPT, open Settings > Personalization > Memory and turn on "Reference chat history" if your account shows it. In Claude Code or Codex, start it in the folder you work in most, so it can read your files.
  • 2Paste the prompt into a new chat.Send it as it is. It tells you how far back it could read. If that's only a couple of weeks, the list will be short. Run it again in a month.
  • 3Pick from the top 10.It stops with one table, ranked by hours saved a month, and a count of how often it found each one. Something it found six times beats something it found three. Pick two or three to start, not all ten.
  • 4Approve the builds.For each one you pick, it writes a SKILL.md or the exact prompt for a scheduled task. If your tool lets it create them itself, it does. If not, it hands you the file. Where each one goes is below.

Where skills go

ToolWhat to do
Claude appTurn on "Code execution and file creation" in Settings > Capabilities. Then Customize > Skills, click "+", then "+ Create skill", then "Upload a skill". It takes the skill folder as a ZIP file. Skills work on the free plan too.
Claude CodeSave each one as ~/.claude/skills/<name>/SKILL.md. It's then available in all your projects on that machine.
CodexType $skill-creator and it walks you through it. Or save the folder in ~/.agents/skills so it works in any repo.
ChatGPTStandalone skills live in the ChatGPT desktop app, under Skills in the sidebar. In ChatGPT Work, type @skill-creator.

Where scheduled tasks go

ToolWhat to do
ClaudePaid plans. Describe the task with a day and a time, like "Every Monday at 8 AM, …". Check the name, schedule and instructions it proposes, then click "Schedule". Every task sits under "Scheduled" in the left sidebar, and they run even when your computer is asleep.
Claude Code DesktopIn the Code tab, open Routines, click "New routine" and choose Local. Weekly lets you pick a day and a time. Local tasks only run while the app is open and your computer is awake.
ChatGPT and CodexWhen your workspace has them turned on, create them from Chat or ChatGPT Work on the web, or in the ChatGPT desktop app, and review runs in Scheduled. The Codex CLI has no scheduling screen, so set the task up in ChatGPT once the prompt works.
Menus change and vary by plan and region. If a setting isn't there, it may not be on your account yet. The prompt already covers that: when it can't create something itself, it gives you the file or tells you how to set it up. 03 · The list

What to build. 24 to consider.

Your own history decides what goes first. Use this list to spot what the prompt missed, or to get started if your history is thin.

A · Skills: things you make over and over

  • 01Client proposalTurns call notes and a brief into your proposal layout, with your pricing, scope and case studies. For consultants, agencies and freelancers.
  • 02Branded slide deckBuilds a deck from an outline in your template, fonts and colours, with your usual slide order. For anyone who presents every week.
  • 03Meeting notes to actionsTurns a transcript into decisions, owners and due dates in the same format every time. For managers and project leads.
  • 04Client status updateTakes your notes and task list and writes the weekly update in your voice and your headings. For account managers and PMs.
  • 05Content repurposerTurns one long post, talk or video transcript into a LinkedIn post, a newsletter section and a short script, in your voice. For creators and marketers.
  • 06Email replies in your voiceDrafts replies to the emails you get every week (pricing questions, intro requests, a polite no) from your best past replies. For founders and anyone with a busy inbox.
  • 07Pre-meeting research briefResearches a company or person and returns one page under fixed headings: who they are, what they've said lately, what to ask. For sales, recruiters and investors.
  • 08Spreadsheet to summaryReads an export and writes a one-page summary: the three numbers that moved, and the likely reason. For ops, finance and founders.
  • 09Brand voice checkChecks any draft against your brand guide, swaps the words you never use and flags claims you can't back up. For marketing teams.
  • 10Process doc writerTurns rough notes or a walkthrough transcript into a numbered how-to your team can follow. For ops and team leads.
  • 11Hiring packWrites the job ad, the interview questions and a scoring sheet from a short role brief, in your company's format. For hiring managers.
  • 12Customer answerAnswers common customer questions from your help docs and policies, and flags anything it can't answer instead of guessing. For small business owners and support teams.

B · Scheduled tasks: things tied to a day or a time

  • 01Monday week planEvery Monday at 8am, checks your calendar, inbox and task list, then gives you the week's top three priorities and what to prep. For everyone.
  • 02Weekly pipeline reviewEvery Monday at 8am, pulls open deals from your CRM, flags the ones with no activity in two weeks and drafts a follow-up for each. For sales leads and founders.
  • 03Morning briefEvery weekday at 7am, summarises the last 24 hours of email, Slack and calendar, with anything that needs a reply today at the top. For managers.
  • 04Meeting prepEvery weekday at 8am, writes a short brief for each external meeting that day: who they are and where you left things last time. For sales and consultants.
  • 05Follow-up sweepEvery Thursday at 3pm, finds emails you sent that got no reply in five days and drafts a short nudge for each. For anyone who chases replies.
  • 06Friday wrap-upEvery Friday at 4pm, lists what got done this week from your tasks and sent mail, and drafts the update for your manager or team. For team leads.
  • 07Industry digestEvery Monday at 7am, finds the five stories that matter in your field this week, one line each with the link. For anyone who needs to stay current.
  • 08Competitor watchEvery Wednesday at 9am, checks competitors' sites, pricing pages and news, and lists only what changed. For founders and marketers.
  • 09Content ideasEvery Monday at 9am, pulls the questions people are asking in your niche and your best recent posts, and gives you five ideas for the week. For creators.
  • 10Month-end numbersOn the 1st of each month at 9am, pulls last month's figures from your spreadsheet and writes a summary against the month before. For founders, ops and finance.
  • 11Overdue invoice chaseEvery Monday at 10am, lists invoices past their due date and drafts a polite reminder for each. For freelancers and small businesses.
  • 12Folder tidy-upEvery Friday at 5pm, sorts, renames and files everything in your downloads or shared folder. For everyone.
A scheduled task can only check the tools it can reach. In Claude, scheduled tasks use the connectors you've set up, so connect your calendar, email or CRM first. Tasks that need files on your computer only run locally, so the computer has to be on. If your tool's schedule picker has no monthly option, ask for "the 1st of each month" in plain words.
04 · What to do now

Run it today. Build two.

One skill and one scheduled task is enough to start. You'll feel the second one on the first Monday it runs.

  • If you use Claude or ChatGPT every day: check the history setting in section 02, paste the prompt, and build the top skill and the top scheduled task from its table.
  • If your history is thin: pick one skill and one task from section 03 and ask your AI to build them with you. Run the prompt again in a month.
  • If you live in Claude Code or Codex: tell it to write the skills straight into your skills folder and test each one on a real job before you keep it.
  • If you're on a free plan: skills work on Claude's free plan. Searching past chats and scheduled tasks need a paid plan in Claude, so start with a skill.
