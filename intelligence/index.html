02Research

Start from what already works.

Say "run my research". It pulls the newest videos from the creators you watch, scores each one against that creator's normal and gives you five ranked ideas.

A score of 1 is an ordinary video for that creator, and 5 is five times that. Comments count three times as much as likes, because they take more effort. Pick a number and say "give me hooks for number 2", and it writes hook options for that idea.

No Apify key? Research still runs on YouTube creators, links you paste and your own notes.

04Two video styles

Film it, or don't.

UI story turns a talking-head take into a Reel. Mini me needs no filming at all.

UI story

You film yourself talking, and the edit puts the real thing you're talking about on screen as you say it: footage of a product in use, its interface, a chart or a post. It cuts between three layouts.

A new visual lands about every two seconds, the captions light up word by word in your fonts, and the motion graphics come in your accent colour. The Reel closes on your call to action and plays at 1.15x speed.

Mini me

A pixel character of you, drawn from 3 to 5 photos or from a description, does the talking. You approve the character sheet first, then each pose. Each spoken phrase lands as a giant keyword headline in your colours. The voice-over is your own phone recording, which is free, or an ElevenLabs voice if you add your key.

The kit ships no music. A bed plays under a Reel only once you add tracks you have the right to use.
05Posting

One Reel, six platforms.

Say "post it everywhere tomorrow at 6pm". You get a caption for each platform to read, and nothing goes out until you say yes.

Each post has its own caption and time, and you can cancel any one of them on its own. Without a Zernio key, every Reel still ends with the MP4 and one file holding each platform's caption, ready to post by hand.

07Setup

From a fresh install to "set me up".

Install your agent, get your own copy of the kit, open the folder and say "set me up". Setup is one conversation of 30 to 45 minutes.

  1. 1Install your agentClaude Code or Codex, then sign in
  2. 2Get your copyClone it, or use the template
  3. 3Open the folderRun claude or codex inside it
  4. 4Say "set me up"One conversation, 30 to 45 minutes
  5. 5A test clipIn your colours, at the end of setup
  • 1Install Claude Code or Codex, and sign in.

    For Claude Code, run this in Terminal, as its setup page shows. Then open a new Terminal window, run claude and log in through the browser prompts.

    curl -fsSL https://claude.ai/install.sh | bash

    For Codex, run this instead, as its CLI page shows. Then open a new Terminal window, run codex and choose Sign in with ChatGPT.

    curl -fsSL https://chatgpt.com/codex/install.sh | sh
  • 2Get your own copy of the kit.

    Clone it with these two commands in Terminal:

    git clone https://github.com/Richardeve1997/content-intelligence-kit
cd content-intelligence-kit

    On a new Mac, git clone first asks to install Apple's command line developer tools. Say yes, and run both commands again once they're installed.

    Or press Use this template on the GitHub page and make the new repository private.

    Clone it, don't fork it. GitHub keeps a fork of a public repository public, and you can't make it private. Your copy will hold your voice samples, photos and scripts. They sit in folders git ignores, but anything you ever commit to a fork is public for anyone to read.

  • 3Open the folder and say "set me up".

    Run claude or codex inside the kit's folder, then type "set me up" into the agent, not into Terminal. It checks your Mac, learns your brand, your voice, your audience and the creators you want to learn from, and finishes with a short test clip in your colours.

    It asks about one thing at a time and saves after every step, so you can stop and pick it up later. ONBOARDING.md walks through each step.

  • 4Check your Mac any time.

    Run python3 bin/doctor.py in the kit's folder to see where your Mac stands. It changes nothing.

If you use Codex

Codex reads AGENTS.md, which points it to the same instructions and skills Claude Code uses. Codex usually runs commands in a sandbox that can write only in the kit's folder and the temporary folder, and can't reach the internet. Rendering, installs, research, voice-overs and posting can't run there, so Codex asks before it runs those commands outside the sandbox. Say yes when it asks.

Before each release the kit is installed on a fresh Apple silicon Mac runner on GitHub, then run end to end as a made-up creator in Claude Code and in Codex. One gap remains. No run on a clean Mac has tested three standard Homebrew steps that setup relies on: installing Homebrew itself, brew install uv and brew install node.

09Make it yours

It learns your preferences and keeps them.

Everything the kit learns about you lives in your own folder, me/, and kit updates never touch it.

  • 1Setup writes your files.

    The first conversation produces your brand, voice, audience, watch list and character files. The video styles work from them, which is how a Reel comes out in your fonts, your colours and your voice.

  • 2Feedback becomes a rule.

    When something's off, say so and add "going forward". It fixes this video and writes a rule into your rules file that every later video follows. In Codex, each skill records your corrections in its own Feedback step.

  • 3Edit anything in your copy.

    The public repo takes no pull requests, because the kit has one maintainer. So clone it and change whatever you like in your own copy. For preferences you want to last, use rules.

Your voice samples, photos and scripts sit in folders git ignores. If you put your copy on GitHub, keep the repository private. Section 07 explains why a fork can't be.
10Updates

Updates leave your files alone.

Say "update the kit". It checks how your copy was made first, because a clone and a template copy update in different ways.

Updated when you say so

Kit files

  • CLAUDE.md and AGENTS.md
  • The skills in .claude/skills/
  • The code in kit/ and bin/
Never touched

Your files

  • me/: brand, voice, watch list, rules
  • work/: your videos
  • research/: your runs
  • .env: your keys
  • A clone of the repo updates with git pull. Your folders and .env are gitignored, so a pull leaves them alone.
  • A template copy, a clone pointed at your own repository or an unzipped download updates from the latest release through bin/update_kit.py. It shows what would change before it changes anything.
  • A kit file you edited stays as you left it, unless the release changed it too. Then your version is copied to me/kit-backups/ before it's replaced.

When a release changes the dependencies, the update tells you and names the commands to run:

uv sync --group video --group research --inexact
npm ci
11What's not in it

What my setup does that the kit doesn't.

The Reel shows my own system. Version 1 of the public kit leaves some of it out.

Version 1

In the kit

  • Onboarding
  • Research
  • UI story
  • Mini me
  • A review before a Reel counts as done
  • Posting through Zernio
  • Feedback saved as rules
  • Updates
Left out

Only in my setup

  • Comment-to-DM rules, the part that sent you this page
  • Email capture and resource pages
  • An analytics dashboard and a weekly performance review
  • Other edit styles and script methods, clips, plain motion graphics, carousels and thumbnails
  • A standalone script skill (script writing lives inside the two video styles)
  • Slack as a research input
  • Cowork, which can't run the video renders
Windows, Linux and Intel Macs aren't supported either: setup stops on them. In the Reel I mentioned tracking how your posts perform. In the kit, Zernio brings your own results back in as a research input. The analytics dashboard and the weekly review from my setup aren't part of version 1.
12What to do now

Pick one. Use it today.

Reading this won't get you a video. Setup is the first step, and it takes 30 to 45 minutes.

  • If you have an Apple silicon Mac and Claude Max or a paid ChatGPT plan: start at 07 and say "set me up" tonight.
  • If you don't want to pay for the extra tools yet: start anyway. Each optional key has a free way round it (06).
  • If you want to read before you install: the README and ONBOARDING.md cover every step.
  • If you're on Windows, Linux or an Intel Mac: setup stops on those computers, so version 1 won't run for you.
