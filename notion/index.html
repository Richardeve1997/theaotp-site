01Start here

Notion's co-founder runs every agent off one vault.

Akshay Kothari, co-founder of Notion, built a context vault in Notion and connected every agent he uses to it. They write back new memories, skills and preferences, then sync each morning.

His vault is five pages: Soul, Memory, Artifacts, Skills and Lessons. Memory is the one doing most of the work, a database where each row is one fact and a Source column says which agent saved it. In October Notion turned the idea into an official setup prompt anyone can use.

0310 tips

10 tips for running an AI-native business.

The setup is the easy part. These are the habits that make one shared brain pay off across a team.

1

Own your context. Rent the intelligence.

Models change every few months. What you've taught them about your business shouldn't have to start over each time. Keep that context somewhere you own, and plug whichever model is best this month into it.

"Own your context. Rent the intelligence."Akshay Kothari, co-founder of Notion, on X, 10 Sep 2026

Read the post on X

2

Give every agent the same brain.

When each AI learns about you on its own, you repeat yourself in every chat. Point them all at one place and they work from the same decisions, preferences and project notes. Notion's prompt calls this "one shared brain for every agent".

3

Write the rules down once.

A short rules page tells every agent where things live and how to use the brain: search it before answering, save what's new, keep it current. Notion's prompt sets this up as the Agent Operating Guide, so a new chat doesn't start from zero.

4

One fact per row, with its source.

Kothari's Memory database holds "one independently updatable fact per row", and a Source column says which agent saved it. Small rows are easy to fix when something changes, and the source tells you who to ask.

Watch his walkthrough on X

5

Let it learn from the whole team.

The brain gets better when everyone feeds it. A teammate tells Claude the Q2 plan changed, and the next person asking ChatGPT gets the new plan. Notion's prompt is written for the user and their teammates, not one person alone.

6

Keep the work next to the brain.

If your client docs, notes and projects already live in Notion, the brain sits in the same place as the work. Agents connected through Notion can search your workspace, create and edit pages and manage databases, so there's nothing to copy across.

7

Let agents keep boards and pages current.

When the brain learns something new, the pages that depend on it can be updated too: a card moves on the task board, a line changes on the strategy page. Notion's prompt says it plainly: work "kept up to date by people and agents alike".

8

Run a daily loop.

Kothari's agents write back what they learn and sync each morning. Notion's prompt adds the same idea as a daily check that saves anything new worth remembering. If you want it hands-off inside Notion itself, Custom Agents run on a trigger or a schedule on the Business plan.

9

Decide what gets remembered.

Context in Notion belongs to you, not to a model or a chat history. You can read it, edit it, share it or take it elsewhere, and you decide who sees what. Keep private things private before you connect a whole team.

10

Switch agents without starting over.

A new model comes out, you try it, and it already knows your business on day one because it reads the same brain. That's the whole point: agents come and go, your context keeps growing.

"Agents will come and go. Your context should compound!"Akshay Kothari on X, 10 Sep 2026
04What to do now

Start with one agent this week.

You don't need the whole team on day one. Connect one agent, let it fill the Memory database for a week, then add the next.

  • You already use Notion: paste the prompt into the agent you use most and let it build the rules page and Memory. Then tips 6 and 7.
  • You're new to Notion: start with tips 1 to 3, then the prompt. Keep it to one rules page and one Memory database.
  • You run a team: tips 5, 8 and 9 first. Agree what gets remembered before everyone connects.

See what's possible. Then build it.
