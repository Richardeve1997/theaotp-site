01Before you start

One weekend, four blocks.

Saturday and Sunday each get a morning and an afternoon block, with a prompt for each one. On Monday you've got a quote machine that prices the way you do.

You'll need a Claude account. Projects work on every plan, the free one included (free accounts get up to five). Skills also need code execution switched on: Settings > Capabilities > "Code execution and file creation". In the newer settings layout it's called "Create and edit files".

02Saturday morning

Write down how you price.

Most of your pricing lives in your head. Claude can't use what's in your head, so get it on paper first.

Open a new chat in Claude and paste this

I want to write down exactly how I price my jobs, so Claude can quote for me later.
Interview me one question at a time. Cover:
- every rate I charge (hourly, per unit, per job, minimum charge)
- every extra (call-out, materials markup, travel, after hours, rush jobs, disposal)
- every discount I give, and when (repeat customers, big jobs, cash, off-season)
- what I always include, and what I never include
- how I round numbers and how long a quote stays valid
Wait for my answer before the next question. When we're done, turn it all into one
document called "How I price" with clear headings and a worked example.

Turn on voice and just talk. It's quicker than typing, and you'll remember more.

When it's done, save the finished "How I price" document as a file. You'll upload it this afternoon.

03Saturday afternoon

Put it all in one Claude project.

Now give Claude one place where your pricing is always in front of it.

  • 1Make the project.In Claude, click + New Project. Call it "Quotes".
  • 2Upload your pricing and three emails.In Project knowledge, click + and upload your "How I price" document and your three most-sent emails: the quote email, the follow-up and the "here's what's included" one. Paste them into a text file or upload them as they are.
  • 3Set the instructions.Click Set project instructions, paste the block below, then click Save instructions.

The project instructions

You write quotes for my business.
Use only the rates, extras and discounts in "How I price". Never make up a price.
If a job needs something that isn't in the document, list it under "Need to check"
instead of guessing.
Show the working: every line item, its quantity, its rate and the total.
Write the quote email in my voice, using my sent emails as the guide for tone and length.
Ask me for anything you need before you write the quote.

Everything you upload to the project is used in every chat inside it, so you only do this once. Claude's help page has the full walkthrough: How to create and manage projects.

04Sunday morning

Test it on last month's jobs.

This is where it gets good. You already know what last month's jobs should have cost, so use them as the answer key.

In a new chat inside the Quotes project, once per job

Here's a job from last month. Write the quote.
[the customer's request, as they sent it]

Then put each quote next to what you actually charged. For every number it gets wrong, tell it why.

When a number is wrong

That's wrong. The callout should be [X] because [reason]. The discount doesn't apply
because [reason]. Update "How I price" so this never happens again, and give me the
new version.

Replace the old "How I price" file in Project knowledge with the fixed version. Run the jobs again until the numbers match what you'd charge. Five to ten jobs is plenty.

05Sunday afternoon

Turn the fixed version into a skill.

A skill is a folder of instructions Claude loads when the job calls for it, so every quote follows the same steps in the same format.

  • 1Make the folder.Make a folder called quote-writer.
  • 2Add the skill file.Inside it, make a file called SKILL.md and paste in the block below. Put your fixed pricing in the marked spot, or keep it in a second file in the same folder.
  • 3Zip it.Zip the folder so quote-writer sits at the top of the ZIP.
  • 4Upload it.In Claude go to Customize > Skills, click +, then + Create skill, then Upload a skill, and pick the ZIP. Make sure its toggle is on.

SKILL.md

---
name: quote-writer
description: Writes a priced quote and the quote email for my business from a customer's request.
---

# Quote writer

1. Read the customer's request. List the work they're asking for.
2. Price every line using the rates, extras and discounts below. Never invent a price.
3. Anything not covered goes under "Need to check".
4. Lay the quote out the same way every time:
   - customer name and job address
   - line items: description, quantity, rate, total
   - extras, then discounts, then the total with tax
   - what's included and what isn't
   - how long the quote is valid
5. Write the quote email in my voice: short, friendly, the total in the first two lines.

## How I price
[paste your fixed "How I price" document here]

If you change the top of the file, keep the name to 64 characters and the description to 200. The skill won't run unless code execution is on (section 01). Claude's help page covers the details: How to create custom skills.

06Monday

Send the price.

A customer asks for a price. Paste their message into Claude inside the Quotes project, and say this.

Quote this.

You get the line items, the total and the email, laid out the same way every time. Check the numbers, hit send, then finish your coffee.

07Where to start

Pick your starting block.

You don't have to start on Saturday morning if you've already done part of it.

  • 1Your prices only live in your head.Start at section 02 and let Claude interview you.
  • 2Your prices are already written down.Skip to section 03 and upload that document as your "How I price".
  • 3You already quote inside a Claude project.Start at section 04 and test it on last month's jobs.
  • 4Your quotes come out in a different layout every time.Go to section 05 and make the skill.
